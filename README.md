Универсальное **полностью офлайн**-приложение расписания для студентов любого учебного заведения. Никакого сервера и API: студент сам собирает семестр во встроенном конфигураторе — даже если расписание его вуза существует только в виде таблички в PDF.

> [!NOTE]
> Приложение не связано с учебными заведениями. Все данные вводятся пользователем и хранятся только на устройстве.

---

## Возможности

**Конфигуратор семестра**
- Единый открытый формат `universal-schedule` (JSON): вуз, группа, курс, семестр, дата начала, число недель, свои звонки, недельный шаблон занятий.
- Занятия: предмет, тип (лекция/практика/лабораторная/другое/доп.), преподаватель, аудитория, подгруппа, чётность (каждую/нечётные/чётные недели), диапазон недель.
- Экспорт и импорт расписания файлом (.json) или через буфер обмена — передать одногруппнику или восстановить резервную копию.
- Открытая спецификация формата + инструкция для ИИ-ассистентов (как собрать JSON из PDF/скриншота расписания): [docs/SCHEDULE_FORMAT.md](docs/SCHEDULE_FORMAT.md).
- Один активный семестр: редактирование в любой момент, удаление и пересборка.

**Расписание**
- Календарь: лента недель + месячный календарь с точками пар, нумерация и чётность недель.
- Текущая пара, прогресс до конца, подсветка перемен.
- Заметки к парам и предметам.
- Локальные напоминания о занятиях (работают без интернета).

**Задачи**
- Задачи по предметам: категории, приоритеты, статусы, чеклисты. Привязаны к расписанию, но при удалении семестра не стираются (только вручную).

**Интерфейс**
- Темы: светлая, тёмная, системная (+ секретные оверлеи).
- Раздел «Задачи» включается тумблером в настройках.
- Проверка обновлений: только предупреждение с переходом на GitHub — без скачивания и автоустановки.

## Структура проекта

Kotlin Multiplatform + Compose Multiplatform:

- `shared/` — общий код: локальный формат семестра (`SemesterConfig`), конфигуратор, экраны расписания, задач и настроек.
- `androidApp/` — Android-обёртка.
- `iosApp/` — iOS-обёртка.
- `docs/` — спецификация формата расписания (в т.ч. для ИИ-импорта).
- `tools/` — CI-скрипты версионирования и публикации релизов.

## Сборка

- Android: `./gradlew :androidApp:assembleDebug` (нужен Android SDK).
- iOS: открыть `iosApp/iosApp.xcodeproj` в Xcode на macOS.
